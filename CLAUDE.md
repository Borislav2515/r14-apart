# R14-APART

Vite + React site for premium short-term apartment rental in Vladikavkaz. See [README.md](README.md) for stack and run instructions.

## Design Context

Strategic and visual specs live at the project root — read both before UI work:

- **[PRODUCT.md](PRODUCT.md)** — Register: **brand**. Target users: travelers, couples, families, business guests booking in Vladikavkaz. Primary goal: HomeReserve widget conversion. Personality: premium, welcoming, locally rooted boutique hospitality.
- **[DESIGN.md](DESIGN.md)** — Creative North Star: *"The Boutique Arrival"*. Dark charcoal body, cream type, antique gold accent (≤10% of surface). Fraunces display + Manrope body. Photography-forward; sharp 1px CTAs; no OTA/hotel/AI-landing tropes.

Key principles: photography carries the room; book without friction; boutique not hotel; trust through clarity; calm motion.

Accessibility: WCAG 2.1 AA, reduced-motion support, Russian-first headline overflow testing.

Live mode config: `.impeccable/live/config.json` (Vite SPA, `index.html`).
